# Ansible Collection - agnosticd.aro_workloads

ARO (Azure Red Hat OpenShift) specific workloads for AgnosticD v2.

Roles here are specific to the ARO installation method (`host_ocp4_deploy_installation_method: aro`)
rather than generic across cloud providers; generic OpenShift workloads live in
[`agnosticd.core_workloads`](https://github.com/rhpds/core_workloads).
